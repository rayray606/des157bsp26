Usability Test and Results

I conducted a usability test on Version 1 of my capstone project, which explores the mental health experiences of Korean pastor's kids and possible future outcomes for faith communities. Participants were asked to navigate through the website, read each section, and interact with the reflection feature. Overall, users understood the main purpose of the project and were able to move through the website without major navigation issues. Participants responded positively to the topic and felt that the project addressed an important issue that is not often discussed openly.

The primary feedback was that the website felt too text-heavy and would benefit from more visual elements. Users suggested adding images, icons, animations, and data visualizations to help break up large sections of text and create a more engaging experience. Participants also wanted more opportunities for interaction rather than simply reading information. Several users noted that the future-focused aspect of the project could be emphasized more clearly so that the connection to speculative design is immediately apparent.

Based on the usability test, Version 2 will include several changes. I will add scroll animations using AOS to create a more dynamic storytelling experience. I want to incorporate plans for Chart.js visualizations to present research findings in a more engaging way. Additional visual hierarchy, imagery, and interactive elements will be added to reduce the amount of text on screen at one time. These revisions aim to improve user engagement, strengthen the project's connection to speculative design, and create a more compelling experience overall.
